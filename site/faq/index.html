FAQ

Frequently asked questions

Short answers, each drawn from the README. For anything not covered here, see the README.

Is lea a replacement for Claude Code?

No. lea runs the real agent CLI, Claude Code by default, with your own settings, skills and plugins. It gives it a safe place to run and a deck to run several at once.

Which agents does it run?

Claude Code, Codex, and through Codex any OpenAI-compatible endpoint that serves the Responses API (Ollama, vLLM). Without the deck, lea config tool runs the command of your choice in the container. Providers.

Why not just skip permissions on my host?

On your host, an agent that skips its permission prompts gets everything your user can reach: keys, tokens, your network. In lea it can go just as fast, but what it can reach is fixed by the container and the proxy.

How is it different from a devcontainer?

A devcontainer isolates a toolchain; lea isolates the agent. It adds an egress proxy that refuses private networks, keeps your credentials out, nests its own container engine, audits risky changes on exit, and gives you a deck for many agents.

Does my code leave my machine?

Only the way your agent already sends it: to its model API. lea has no server and no account, and sends no telemetry of its own. Usage metrics go nowhere unless you set LEA_OTEL_UPSTREAM to your own collector.

Where do I approve a database query?

In lox run, in a terminal of your own outside lea. Requests to the Locks (locksql, lockmq, lockfile, locklog, lockhttp) are decided by the Lock Family’s hub, never by lea. The deck answers only the agents’ own permission requests. Add the Locks.

Does lea need lox?

Not to run agents. You need lox 0.9.0 or later for the Locks: lox add sets a lock up in the projects directory, and lox run runs it and serves the decisions. lea itself runs no lox command.

Can an agent reach a service on my LAN?

Not by default. List the hosts it may reach in LEA_INTERNAL_HOSTS, with their port. Egress.

Can agents push and merge on their own?

When you say so. lea delivery on, run on the host, lets every agent of a lea push its own branch, open its pull request and merge it, on the repositories it lists. lea delivery off takes it back.

Does it run on Windows?

Through WSL 2: install and run lea from your WSL distribution, with Docker Desktop. Linux and macOS run it natively.

What does it cost?

lea is free and open source under the Apache License 2.0. You bring your agent’s subscription or API key.
